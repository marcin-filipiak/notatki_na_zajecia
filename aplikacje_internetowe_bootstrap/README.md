# Podręcznik Bootstrap 5 - Od Podstaw

Praktyczny podręcznik do nauki frameworka **Bootstrap 5** napisany z myślą o programistach PHP/HTML. Każdy rozdział zawiera wyjaśnienia, przykłady kodu oraz spójny projekt strony restauracji **"Kuchnia Domowa"**, który budujemy krok po kroku.

> **Wersja Bootstrap:** 5.3  
> **Stack:** PHP + HTML + Bootstrap 5 (CDN)

## Jak korzystać z tego podręcznika

1. **Zacznij od rozdziału 01** - naucz się instalować Bootstrapa
2. **Czytaj rozdziały po kolei** - każdy buduje na poprzednim
3. **Przeglądaj przykłady kodu** - wszystkie dotyczą jednego projektu (restauracja)
4. **Testuj kod** - twórz pliki `.php` i otwieraj w przeglądarce
5. **Projekt końcowy (rozdział 13)** - kompletna strona podsumowująca wiedzę

### Wymagania

- Zainstalowany PHP (lokalny serwer XAMPP/Laragon/Docker)
- Przeglądarka internetowa
- Edytor kodu (VS Code zalecany)
